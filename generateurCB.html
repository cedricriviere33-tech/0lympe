🖨 Codes ZPL pour Zebra ZM400
Comment utiliser ?
1. Sélectionne le produit ou contenant
2. Copie le code ZPL
3. Ouvre le fichier .prn dans Notepad sur le PC Zebra
4. Remplace le contenu par ce ZPL
5. Lance l'impression → le code-barre scanné donnera directement CTOC PRIO

Pourquoi la suite numérique ?
La Zebra encode la valeur interne Excel (ex: 203974850974850...) quand le ZPL est généré depuis Hermès. En forçant ^FD[TEXTE] à la place, le scanner relit le texte exact.
Impression en série — ZPL batch

Génère un fichier .prn contenant les ZPL de TOUS les produits d'un coup. À envoyer directement à la Zebra via copy fichier.prn \\\\serveur\zebra ou via ZebraDesigner.
